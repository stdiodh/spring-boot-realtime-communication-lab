# 시퀀스 맵

## 이 레포 안의 성장 흐름

### 08. 실시간 통신

- WebSocket endpoint에 연결합니다.
- 클라이언트가 메시지를 보냅니다.
- 서버가 받은 메시지를 topic으로 다시 보냅니다.
- 연결된 클라이언트가 실시간으로 메시지를 받습니다.

## 왜 이 레포를 따로 분리했는가

`spring-boot-redis-cache-lab`은 조회 성능과 캐시 흐름을 다루는 레포입니다.
반면 이번 주제는 실시간 연결 유지와 메시지 전달이라는 전혀 다른 학습 도메인에 더 가깝습니다.

그래서 08부터는 새 토픽 레포로 분리해 실시간 연결 유지와 메시지 전달 문제를 별도로 다룹니다.
