# 실시간 통신 체크리스트

## 실습자 체크리스트

- [ ] HTTP와 WebSocket의 차이를 설명할 수 있습니다.
- [ ] 메시지 DTO 역할을 설명할 수 있습니다.
- [ ] 서버가 받은 메시지를 topic으로 다시 보내는 흐름을 말할 수 있습니다.
- [ ] 테스트 페이지에서 메시지를 보내고 다시 받는 과정을 설명할 수 있습니다.
- [ ] 채팅/알림 같은 기능에서 왜 이런 구조가 필요한지 말할 수 있습니다.

## 리뷰어 / PPT 체크리스트

- [ ] HTTP 요청/응답과 실시간 통신 차이 그림이 있는가
- [ ] connect -> send -> receive 시연 포인트가 준비되어 있는가
- [ ] endpoint와 topic 경로를 구분해 설명할 수 있는가
- [ ] 메시지 저장이나 채팅방 관리까지 확장하지 않는 이유가 분명한가
- [ ] 이번 시퀀스가 실시간 통신 입문이라는 점이 선명한가
